# Manual de usuario — Maykel Repuestos 2

## Cliente (sitio público)
1. Entrar al sitio y buscar por texto, categoría o por vehículo (marca → modelo → año).
2. Los productos muestran disponibilidad, nunca precio.
3. Agregar al carrito de reserva, ingresar nombre y teléfono y confirmar. Se entrega un folio `RES-####` y un comprobante PDF.
4. Si un producto está agotado, el botón "Me interesa" registra la demanda.

## Vendedor / administrador (panel)
Entrar con el enlace **Admin**. Tras 5 intentos fallidos la cuenta se bloquea 15 min. La sesión dura 8 h.
- **Inicio / Analítica**: ventas, reservas y demanda insatisfecha.
- **Reservas**: confirmar o cancelar (las reservas pendientes no descuentan stock).
- **Ventas**: registrar venta en sucursal; descuenta stock automáticamente.
- **Stock / Catálogo**: crear, editar y eliminar productos; alerta de stock bajo.
- **Usuarios y roles** (solo superadmin): crear cuentas y permisos.
- **Configuración**: editar textos del sitio.
- Reportes PDF de ventas, reservas y stock.

## Capacitación (sugerida, 1 h)
Demo de cada rol, ejercicio: crear reserva → confirmarla → registrar venta → revisar dashboard.
